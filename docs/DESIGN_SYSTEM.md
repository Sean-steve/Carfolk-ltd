# Carfolk Design System v0.1

**Source identity:** client-supplied Carfolk LTD logo, **Quality & Affordability** tagline.

| Token | Hex | Role |
| --- | --- | --- |
| Ink | #101622 | Hero, navigation and footer |
| Graphite | #1C2534 | Dark surfaces |
| Red | #E21B2D | Primary buttons and emphasis |
| Gold | #F49B28 | Logo-aligned accent |
| Canvas | #F5F6F8 | Light section background |
| White | #FFFFFF | Cards and white space |

**Typography:** Manrope 700–800 headings; DM Sans for body, specifications and forms, with system font fallback.

**Reusable frontend:** Brand, Button (primary/outline/ghost), Header, layout containers, form controls, status badges and typographic patterns. Style rules are in `apps/web/src/styles.css`.

**Accessibility baseline:** semantic headings, labelled inputs, visible keyboard focus, generous tap targets, sufficient contrast, reduced-motion support and mobile-first responsive layout. Decorative artwork is not a substitute for meaningful product images.

**Governance:** Phase 0 previews may contain marked illustrative components but no fake live vehicles, exaggerated claims, or placeholder customer testimonials.
